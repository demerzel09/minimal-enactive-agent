# 系譜メモ: 中心仮説はどう出現したか

> 作成日: 2026-06-11
> 目的: 中心命題（「エージェンシーの本質は認知能力ではなく…」）が、どの問いから、
> どのような整理を経て立ち上がったかを一枚に記録する。
> 出典: `discussion_summary.md`, `research_philosophy.md`, `architecture_principles.md`

## 1. なぜこのメモがあるか

中心命題は `research_philosophy.md` §2 に結論として置かれ、その正当化は §3（LLM 論証）にある。
しかし「どうやってそこに至ったか」は `discussion_summary.md` に分散しており、一望できなかった。
このメモはその系譜を一本にまとめる。

## 2. 系譜（7段階）

1. **出発点 = 日常経験**「今日は何をしようか？」
   目標達成の計画ではなく、**目標そのものが立ち上がる瞬間**への関心。(`discussion_summary.md` §1)

2. **最初の問いの定式化**
   「外部目標が固定されていないとき、システムは次の行動候補を選ぶために内部で何を最適化しているのか？」(`discussion_summary.md` §1)

3. **語の乱立期**
   内在的価値信号・最小知能・予測・記憶・モード切替・内部状態 —— 概念が互いに重なり、抽象度も不揃いだった。(`discussion_summary.md` §2)

4. **枠組みの転換**
   「一般的な知能」として捉えるのをやめ、**生物的エージェンシーの最小形**として捉え直す。(`discussion_summary.md` §1 末, §2)

5. **2概念への圧縮**
   乱立した語が、**身体-環境の閉ループ** と **状態依存のコヒーレンス駆動** の 2 つに収束。(`discussion_summary.md` §2-3)

6. **価値と報酬の再解釈**
   価値判断を独立要素ではなくコヒーレンス駆動の局所的順位づけとし、**早期のスカラー報酬への還元を避ける**。(`discussion_summary.md` §4, `architecture_principles.md` §5)

7. **LLM 論証での裏打ち → 中心命題の確定**
   LLM が認知能力を身体・動機・閉ループなしに実現した → 認知はエージェンシーの必要条件ではない →
   残余（在ること・動機・帰結）を単離。これを中心命題として確定。(`research_philosophy.md` §3 → §2)

## 3. provenance 上の注意（正直な但し書き）

この系譜は **事後の再構成** である。
`research_philosophy.md` は中心命題を「LLM 論証の結論」として提示するが、
`discussion_summary.md` を読むと、**立場が先に選ばれ、LLM 論証が後から正当化として加わった**ように読める。
つまり「LLM からの厳密な論理的導出」ではなく、**動機 → 整理 → 圧縮 → 裏打ち** という収束過程である。
中心命題は導出された定理ではなく、**選ばれた賭け**として扱うのが正確。

## 4. あえて外したものと、その意図

中心命題は、一般的な知性の議論に出てくる 2 要素を意図的に外している。

| 外した要素 | 理由 | 出典 | 性質 |
|---|---|---|---|
| **認知能力** | LLM が分離可能と示した。残余（エージェンシー）を単離するため。認知は「入力」ではなく「上に出現する観察対象」 | `research_philosophy.md` §3, §2 | 後で創発を観察（排除ではない） |
| **スカラー報酬** | 「報酬最大化から行動が出る」という答えを前提に焼き込むのを避けるため | `architecture_principles.md` §5, `discussion_summary.md` §4 | 設計方針であって制約ではない |

いずれも **永久排除ではなく「いま入れない」**。
認知は創発するか観察する対象、報酬は必要なら「内発的価値信号」として h の力学に位置づけ直す余地を残す。

なお、報酬は半分しか外れていない点に注意（GA の適応度＝採餌目的の最大化）。
詳細は `critical_review_meta_neuro_evo.md` §2。

## 5. 一行での結晶

> 「今日は何をしようか」という目標生成の問いを、語の整理で 2 概念に圧縮し、
> LLM が認知を切り離して見せた残余として、エージェンシーを中心命題に据えた。
> ——ただしこれは導出ではなく、選ばれた賭けである。
