# 拡張原則: 認知（LLM）との結合

> 作成日: 2026-06-11
> 位置づけ: `architecture_principles.md`（h/m/i/a の体制原則）の姉妹文書。
> あちらが「最小エージェンシーの内部体制」を定めるのに対し、本書は
> 「その上に認知（LLM）をどう結合し、最小知性へどう近づくか」の原則を定める。
> 状態: 長期的・探索的（まだ実装にコミットしていない。原則層での合意）。
> 関連: `genealogy_central_hypothesis.md`, `critical_review_meta_neuro_evo.md`,
> `environment_first_roadmap.md`

---

## 1. この文書の目的

このプロジェクトには、純粋な構成論的興味に加えて、実利的な狙い（やや妄想的な長期目標）がある。

> ある主体性を定義したとき、それがつくる社会の中で、知性的な行動（LLM のような認知）が
> 勝手に選ばれて創発するのではないか。

そのためには認知と報酬（価値）が必要になるが、両方とも非常に複雑である。
特に **旧脳（本能的・進化的に獲得されたノウハウ）を最初からシミュレーションで再獲得するのは
ほぼ不可能** という危惧がある。

この危惧への応答として、「LLM の能力を出発点に置き、逆方向に少しずつ最小知性へ近づける」という
発想が出た。本書は、その発想を **可能にするための原則** を定める。
手順（アプローチ）は道具とともに差し替わるが、これらの原則はどの手順を選んでも生き残る。

---

## 2. 中心的な組み替え: 「LLM の縮小」を捨てる

最初に、魅力的だが誤った道を一つ外す。

**「LLM を少しずつ削って最小知性に近づける」は失敗する。**

理由は、**LLM の知性（テキスト統計に根ざす）と、最小エージェンシーの能力（閉ループに根ざす）が
同じ軸の上になく、直交している** から。LLM を削っても主体性の方へは動かず、
**ただの劣化した LLM** になる。両者の間に連続的な道は存在しない。

唯一その道を作れるのは **環境の要求** である（原則 C）。

---

## 3. 地図: 旧脳と新脳

脳の構造で見ると、危惧していた「再現不能な部分」と「借りられる部分」が分離できる。

| | 中身 | このプロジェクトでの扱い |
|---|---|---|
| **旧脳**（皮質下：動因・恒常性・情動・報酬回路） | 進化的に獲得した本能のノウハウ | **手で最小に作る**（h＝神経修飾トーン、b_h＝動因、m＝行動レジーム）。生物でも旧脳は低次元なので作りうる |
| **新脳**（新皮質：言語・抽象・世界知識） | テキストから獲得される認知 | **LLM から借りる**（再進化させない） |

決定的な事実: **LLM は新脳であって、旧脳のノウハウを含んでいない。**
したがって「LLM を削って旧脳を取り出す」ことはできない（そこに無い）。
旧脳は手で作り、新脳は LLM で借り、両者を **結合** する。
最小知性は削った先ではなく、**両者をつなぐ最小のインターフェース** として立ち上がる。

この分割は LeCun の自律機械知能（AMI）構想と一致する——
intrinsic cost（動因＝旧脳の類似物）は小さく手設計し、world model（認知）は大きく学習させる。
「本能は人工系では設計してよい」が、「最初からシミュレーションは不可能」への答えである。

---

## 4. 拡張原則

### 原則 A: 旧脳は作り、新脳は借りる
認知（新皮質）は再進化させず LLM から借りる。
動因・恒常性・情動（旧脳）は手で最小に作る。
**禁止**: LLM から旧脳を取り出そうとすること（そこに無い）。

### 原則 B: LLM は縮小対象にしない
簡素化して削るのは **生徒側の接地構造** であって、LLM ではない。
LLM は **教師か皮質** として系の外／上に置く。
これで最小エージェントはクリーンに保たれ、他の知性（LLM 等）との比較可能性が壊れない。

### 原則 C: 上と下が出会う共通軸は環境の要求だけ
環境が「接地した主体性」と「認知」の両方を要求しない限り、
トップダウン（LLM）とボトムアップ（最小エージェンシー）は出会わない。
**要求のない環境での縮小は、ただの劣化**（原則 2 の帰結）。
中点は環境の複雑さが決める。

### 原則 D: 動因は変調であって最大化ではない
価値（旧脳）は precariousness（脆弱性）として、
**「どの認知を動員するか」をゲート（変調）する**。
スカラーとして最大化した瞬間に強化学習へ堕ちる。
これは「報酬なし」（`architecture_principles.md` 原則 5）の核を守る制約。
実脳で神経修飾が皮質処理をゲートするのと同型。

### 原則 E: すべての代用品を代用品とラベルする
GA ＝選択の代用品、存続信号＝複製が導出したはずのものの据え置き、
LLM ＝再進化させない新皮質。
**何が「産物の層」で、何が「生成の根源（コピー）」かを混同しない。**
このプロジェクトは産物の層を手で作る立場であり、根源（複製）はモデル化しない
（だから存続可能性を複製から創発させる道は取れない。詳細は §6 と
`critical_review_meta_neuro_evo.md`）。

## 5. 原則が許すアプローチ（実例・実現性順）

以下は原則 A-E が許す具体手順の例。手順は差し替え可能で、原則がその採否を決める。

### (2) LLM を教師／行動オラクルにして、最小の生徒へ蒸留する ← 最も実現可能・最もクリーン
プロンプト＝行動仕様（ニッチの定義）。LLM に環境内で目標行動を生成させ、
最小の接地アーキテクチャがそれに一致するよう探索／蒸留し、段階的に簡素化して
どこで壊れるかを測る。
- LLM は最終系の外（教師）に留まる → 原則 B を満たす。比較可能性が保たれる。
- 「逆方向に少しずつ最小へ近づける」を正しく実装した形（削るのは生徒、LLM ではない）。

### (1) LLM を皮質として旧脳コアに結合し、最小インターフェースを探す ← 長期的に最有望
閉ループの旧脳コア＋動因を作り、環境が認知を要求したときだけコアが LLM を照会する。
コアが上へ何を渡し、LLM が下へ何を返すか、その最小の結線を探す。
最小知性＝最小コア＋最小インターフェース（AMI の旧脳/新脳分割）。
- 生物学的に正しい（旧脳が認知を recruit する）。インターフェース設計が研究的に重い。

### (3) LLM 社会＋選択＋蒸留 ← 妄想の本体・高分散
複数 LLM エージェント＋資源競争／複製で社会を作り、勝った戦略を観察し、
勝者の知性的行動を最小機構へ蒸留する。科学的価値は最後の蒸留にある。

### 避けるべき形
**単純環境で LLM を素朴に縮小する** — 原則 2 の理由で、最小知性ではなく劣化 LLM にしかならない。

## 6. 認知と報酬の複雑性への対処

「認知も報酬も必要だが、両方とも複雑」への解は、旧脳/新脳の分割から自然に出る。

- **報酬を設計スカラーにしない**（RL に堕ちる）。代わりに旧脳コアが価値／動因を担う
  —— precariousness として（option C, `critical_review_meta_neuro_evo.md`）。
  報酬回路は旧脳なので、これは生物学的に正しい。
- 動因は **最大化される目標ではなく、LLM 皮質のどの認知資源を動員するかを変調する**（原則 D）。
  最大化しないから RL に堕ちず、変調するから認知に接地が入る。

結果: **旧脳（手設計・最小・変調する動因）＋ 新脳（LLM・学習済み・認知）、
結合は環境要求が駆動。** 報酬は最後まで設計スカラーにならず、認知は再進化させず借りてくる。
2 つの危惧（旧脳の再現不能性、認知/報酬の複雑性）が同時に解ける。

---

## 7. 既存議論との接続

- **比較可能性**: 原則 B が、`critical_review_meta_neuro_evo.md` の「産物の層では LLM と比較可能」を
  実装レベルで保証する。LLM を系の外に置くことで、最小エージェントは産物として清潔に保たれる。
- **2 つの根源（複製 vs 自己維持）**: 原則 E が、存続可能性を「複製から創発」させられない理由を固定する。
  プロジェクトは根源（コピー）をモデル化しないと決めているため、存続信号は
  「正直に据えた代用品」（precariousness, option C）として入れるしかない。
- **中心命題**: 本書は「認知はエージェンシーの上に出現する」（`research_philosophy.md` §2）を、
  「出現を待つ」だけでなく「LLM を皮質として結合して接続する」という実利的経路で補完する。
  ただしこれは命題の証明ではなく、工学的なショートカットであることに注意（原則 E）。

---

## 8. 一行でのまとめ

> 削るのは LLM ではなく生徒の構造。再現しないのは旧脳ではなく新脳（LLM が肩代わり）。
> 共通の物差しは環境の要求。動因は最大化せず変調する。代用品は代用品とラベルする。
> 最小知性は「LLM の縮小先」ではなく「旧脳コア＋LLM 皮質をつなぐ最小インターフェース」として立ち上がる。
